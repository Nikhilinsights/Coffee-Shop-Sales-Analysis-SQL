# ☕ Coffee Shop Sales Analysis using SQL

## 📌 Project Overview

This project analyzes coffee shop sales data using SQL Server to solve real-world business problems and generate actionable business insights.

The analysis focuses on sales, customers, products, cities, revenue, and product demand.

## 🎯 Business Objective

The objective of this project is to use SQL to answer important business questions that can help the company understand market demand, sales performance, customer behavior, and product performance.

## 🔍 Business Problems Analyzed

1. Estimated coffee consumers in each city
2. Revenue generated by each city in Q4 2023
3. Number of units/orders sold for each coffee product
4. Product performance analysis
5. Customer purchasing behavior
6. City-wise sales performance
7. Revenue analysis
8. Product demand analysis
9. Market opportunity analysis
10. Business insights for expansion and decision-making

The analysis helps identify:

- Cities with higher potential coffee consumers
